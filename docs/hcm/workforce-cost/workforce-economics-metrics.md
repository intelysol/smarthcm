# Workforce Economics & Productivity Metrics

## Key Performance Indicators
- **Cost per FTE**: $\text{Total Workforce Cost} / \text{Average FTE}$
- **Cost per Employee**: $\text{Total Workforce Cost} / \text{Headcount}$
- **Cost per Labor Hour**: $\text{Total Labor Cost} / \text{Actual Worked Hours}$
- **Cost per Productive Hour**: Benchmark factoring non-productive time (e.g. 85% utilization).
- **Overtime Cost Ratio**: $\text{Overtime Cost} / \text{Total Labor Cost} \times 100$
- **Contractor Ratio**: $\text{Contractor Cost} / \text{Total Workforce Cost} \times 100$
