# Labor Cost Allocation Engine

## Purpose & Scope
The allocation engine distributes direct and indirect workforce costs across the organization's financial dimensions:
- **Source**: Department, individual employee, cost center, or indirect overhead pool.
- **Destinations**: Target cost centers, specific client projects, or receiving departments.
- **Audit Logging**: Every allocation run logs the applied rule, execution timestamp, and source-to-target amounts in `hcm_workforce_cost_audits`.
