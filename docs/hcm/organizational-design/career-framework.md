# Career Framework & Capability Architecture

## Overview
The **Career Framework** connects Job Architecture with employee development, enabling clear progression routes and capability benchmarks.

---

## Integration with Career Domain
* Reuses existing `CareerSkill`, `CareerSkillCategory`, and `CareerSkillLevel` models.
* Reuses existing `CareerPath` and `CareerPathStep` structures.
* Provides non-binding eligibility guidance based on required skills, target competencies, and minimum experience years.

---

## Non-Autonomous Progression Rule
Career frameworks define paths and criteria for growth. The system **never automatically promotes an employee** or alters position assignments without an authorized Core HR Personnel Action and manager/HR approval workflow.
