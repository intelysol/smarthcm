# Device Integration Adapters

## 1. Supported Ingestion Protocols
- **Biometric Terminals**: ZKTeco, Suprema, Hikvision via Integration Hub adapters
- **RFID & Proximity Cards**: Turnstile and gate controllers
- **Web Portal Punch**: In-app digital punch with browser timezone capture
- **Mobile Punch**: Mobile clock-in with optional GPS geofencing metadata
- **CSV / File Import**: Asynchronous bulk import with preview and validation dry runs
