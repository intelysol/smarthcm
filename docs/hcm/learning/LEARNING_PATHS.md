# Learning Paths & Career Progression

## Overview
Learning Paths provide structured, multi-stage development roadmaps tied to job families and career aspirations.

```text
Junior Software Engineer
         ↓ (Complete Foundational Coding Path)
Software Engineer
         ↓ (Complete Distributed Systems & Architecture Path)
Senior Software Engineer
         ↓ (Complete Technical Leadership Path)
Principal Engineer / Engineering Manager
```

## Items in a Learning Path
- Required Courses
- Recommended Electives
- Practical Projects & Capstone Assignments
- External Certifications
- Mentorship & Coaching Milestones
