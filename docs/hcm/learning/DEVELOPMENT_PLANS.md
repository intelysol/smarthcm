# Individual Development Plans (IDP)

## Overview
Individual Development Plans (IDP) bridge employee career goals, performance reviews, and organizational capability needs.

```text
Development Goal (e.g. Master Cloud Solution Architecture)
   │
   ├── Skill Gap: Kubernetes & Infrastructure as Code
   ├── Competency Target: System Resilience
   │
   └── Concrete Development Activities:
         ├── Activity 1: Complete Cloud Architecture Course
         ├── Activity 2: Bi-weekly Mentoring with Principal Engineer
         ├── Activity 3: Lead Migration Project (Stretch Assignment)
         └── Activity 4: Pass AWS Solutions Architect Exam
```

## Lifecycle States
- `draft`: Created by employee or manager.
- `active`: Sanctioned with agreed milestones and target dates.
- `completed`: All associated development activities successfully accomplished.
- `cancelled`: Deprecated due to organizational re-prioritization.
