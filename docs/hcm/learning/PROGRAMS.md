# Learning Programs & Curricula

## Overview
A Learning Program packages multiple courses into a unified curriculum.

### Example: Leadership Development Program
1. Course 101: Foundational People Leadership
2. Course 102: Coaching and Performance Feedback
3. Course 103: Strategic Decision Making
4. Course 104: Conflict Resolution and Difficult Conversations

## Program Completion Rules
- `all_required`: Every course in the program must be completed.
- `elective_credits`: Learners must complete core courses plus a minimum number of elective credit units.
- Program certificates are generated once all course requirements are satisfied.
