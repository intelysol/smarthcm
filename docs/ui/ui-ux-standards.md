# Enterprise UI / UX Standards & Corporate Design System

## 1. Corporate Design Tokens

All application shells adhere to the authoritative corporate tokens:

| Token | Hex Value | Semantic Usage |
|:---|:---|:---|
| **Navy (Primary)** | `#1E3A5F` | Primary branding, top navigation headers, primary buttons |
| **Dark Navy** | `#142A44` | Hover states, active borders, manager accents |
| **Gold (Accent)** | `#C9A227` | Active indicators, action highlights, primary badges |
| **Gold Light** | `#F4E7B2` | Contrast text on dark buttons, secondary accents |
| **Background** | `#F7F9FC` | Clean neutral application body background |
| **Surface** | `#FFFFFF` | Card surfaces, modals, popovers, dropdown menus |
| **Text** | `#1F2937` | High contrast body typography |
| **Text Muted** | `#6B7280` | Secondary labels, descriptions, timestamps |
| **Success** | `#16805C` | Operational health, approved requests, active tenants |
| **Warning** | `#B7791F` | Pending approvals, review cycles, expiring items |
| **Danger** | `#C0392B` | Rejected requests, failed queues, security alerts |
| **Info** | `#2563EB` | Neutral notices, info badges |

## 2. Density Rules by Workspace

- **High Information Density (Admin & Operations)**: Compact tables, bulk actions, tabular datasets, multi-field filters.
- **Medium Information Density (Manager & Executive)**: KPI scorecards, visual roster status, team approval drawers, capacity graphs.
- **Low Information Density / High Simplicity (Employee Self-Service)**: Clean card layouts, personalized greetings, single-action punches, clear balances. Zero administrative sidebars.
